## 📖 نظرة عامة

**SAYODA CYBER FORCE** منصة تعليمية عربية متكاملة متخصصة في **الأمن السيبراني**، مصممة لتأهيل جيل جديد من خبراء الأمان الرقمي عبر محتوى عالي الجودة ونظام تعليمي تفاعلي محفّز.

### 🎯 الرؤية
أن نكون **المرجع الأول** للتعلّم السيبراني باللغة العربية.

### ✨ المميزات الرئيسية
- 🎓 **محتوى منظّم ومتدرّج**
- 🏆 **نظام نقاط (XP) ومستويات**
- 🏅 **شارات وإنجازات**
- 🔒 **نظام أكواد فتح** للمحتوى الحصري
- 👥 **نظام دعوات** بمكافآت
- 📱 **PWA** — يعمل بدون إنترنت
- 🛡️ **حمايات متقدمة** ضد النسخ والتنزيل
- 🎨 **تصميم عصري** — ثيم داكن/فاتح
